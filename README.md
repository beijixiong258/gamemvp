文档和需求交流使用[规则文档中的规范术语](docs/MVP/规则与数值.md#术语与规则状态)：系统操作使用玩法原名，以身入局加“（手动）”，例如阅读／阅读（手动）、考试／考试（手动）。操作方式、主要行动额度、游戏回合和对话轮次分别判断。当前已实现动态体力上限、禁止透支、每回合共享一次主要行动、按操作区分的体力消耗及手动结束回合；体能增长只提高上限，不补当前体力。接口签名、字段和依赖以源码为准，已有存档以数据库及对应 `memory/` 文件为准。官职等后续设计不属于书生线范围。

正常考试路线以读书和固定练习为主要成长来源，人物互动提供额外收益；当前书目为 7 本免费教材和 8 本付费选修书，已增加后半程选修内容，活动、收入及县试后玩法仍未扩展。人物对话与自定义行动共用每人物每游戏回合一次正向成长额度，独立 AI 行动消耗 15 点体力；阅读、考试分别按自己的基础成本结算。考试（手动）由答卷主导评分。公测数值目标为超轻策略、正常玩家最终县试通过率约 75%；具体模拟结果与假设见[规则与数值](docs/MVP/规则与数值.md#mvp-成长与数值设计方向)，不宣称真实玩家实测达到目标。
