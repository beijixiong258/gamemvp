# 豪杰成长计划plus · 启动与部署

日常按“数据库 → 后端 → 前端 → 浏览器”启动。当前为单人网页 MVP，程序实际联调仍需本机确认。

## 本机手动启动

| 服务 | 地址 | 用途 |
| --- | --- | --- |
| MySQL | `127.0.0.1:3306`，库 `mvp` | 存档与业务数据 |
| Java 后端 | `http://localhost:8080` | /api 接口 |
| Vue 前端 | `http://localhost:5173` | 游戏页面 |
| 前端产物预览 | `http://localhost:4173` | 构建后才使用 |

1. 打开 Docker Desktop，启动现有 `local` 分组内的 `mysql` 容器；已运行则直接继续。也可在 PowerShell 7 手动执行：

   ```powershell
   Set-Location -LiteralPath 'C:\Users\user\IdeaProjects\mvp'
   docker compose up -d mysql
   ```

2. IDEA 打开当前项目，用 Java 17 运行 [MvpApplication.java](../../src/main/java/mvp/MvpApplication.java)。运行配置的工作目录设为 `C:\Users\user\IdeaProjects\mvp`，用于读取根目录 `.env` 和 `memory/`。出现类似 `Started MvpApplication` 的信息后保持后端运行。若采用命令行，在根目录执行 `.\mvnw.cmd spring-boot:run`，与 IDEA 二选一。

3. 另开 PowerShell 7 启动前端：

   ```powershell
   Set-Location -LiteralPath 'C:\Users\user\IdeaProjects\mvp\src\frontend'
   npm.cmd run dev
   ```

4. 浏览器打开 [http://localhost:5173](http://localhost:5173)，新开局或继续存档。前端自动将 /api 请求转给 8080。前端终端保持运行；结束时按 Ctrl+C，后端在 IDEA 点击停止。

前端依赖当前已安装。换机器或重新安装时，先满足 [package.json](../../src/frontend/package.json) 的 Node 要求，在前端目录执行 `npm.cmd ci`。已有依赖的日常启动无需安装或构建。

[application.yaml](../../src/main/resources/application.yaml) 从根目录 `.env` 读取模型密钥 `MIMO_API_KEY`，前端不读取此文件。仅在缺少配置时填写：

```properties
MIMO_API_KEY=自己的模型服务密钥
```

已有数据库不需日常重新建库。[compose.yaml](../../compose.yaml) 复用本机外部数据卷，全新机器须先准备对应卷；Redis 为共享服务，游戏本轮不要求额外启动。首次建库及旧数据维护见[后端开发](后端开发.md#数据库维护)。

进入旧存档自动调用内容补齐接口，保留钱包、能力、书籍进度、自定义姓名和记忆。关闭前后端不会删除已保存存档；MySQL 为共享服务，结束试玩不需要删数据卷。

## 常见问题

| 现象 | 核对项 |
| --- | --- |
| 5173／8080 被占用 | 确认是否已有本项目实例，使用已有实例或手动停掉重复进程；不自动换端口 |
| 页面打开但读档失败 | 后端、MySQL 是否运行，mvp 库是否初始化 |
| 仅 AI 操作失败 | 根目录 .env、模型服务连通性及账户状态 |
| 等待超时 | 使用“重试原请求”或刷新确认，超时不代表后端取消 |
| 修改场景后入口没变化 | 重启 Vite；修改 Java 或游戏资源后重启后端 |
| 移动目录后缺少凭据／记忆 | 核对后端工作目录及数据库对应的 memory 文件 |

## 构建与上线

在前端目录手动执行 `npm.cmd run build`，产物为 `src/frontend/dist/`；不会自动清空旧产物，需要干净交付时先移入指定垃圾桶。`npm.cmd run preview` 仅在 4173 预览已有产物，后端仍需运行。

```text
用户浏览器 → 正式 HTTPS 网址
              ├─ 页面与图片等静态文件 → dist
              └─ /api → Java 后端 → MySQL + memory
```

正式静态文件与后端可以同机托管，由统一域名提供入口；后端可在服务器内部继续用 8080，用户无需安装 Node、Java、MySQL。正式服务使用 Web 服务器或后续 Spring Boot 静态资源装配，不使用 Vite 开发／预览服务。

本项目尚未部署公网、配置 HTTPS 或静态资源装配。当前无账号与按用户的存档权限，多用户公开使用前需补齐；更新服务器程序时保留数据库与对应 memory，版本号沿用项目现值。
