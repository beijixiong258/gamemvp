# 随机种子

> MVP 后续方案，尚未实现。当前掷骰规则见[规则与数值](../MVP/规则与数值.md)。

随机种子是一份随机序列的起点，将来可用来重现相同条件下的骰点。当前程序直接生成并保存每次有效行动的骰点；同一请求重传时返回原结果，防止重复执行不依赖种子。

## 候选方案

- 每份新存档生成并保存一个种子，读档沿用；是否允许玩家自选待定。
- 用存档种子、稳定行动编号、骰点用途和算法版本确定骰点。阅读、考试分别区分用途，多次掷骰再加固定子序号。
- 不使用重试次数、模型调用次数或当前时间重新决定同一行动的骰点。
- 已完成行动保留实际骰点。算法更新后不重算旧结果；具体算法、版本字段和旧存档补种子办法待定。

相同种子只在规则版本和行动输入相同时重现骰点，不保证不同操作顺序得到相同人生，也不保证 AI 回答相同。这项设计不承担防作弊、复杂并发处理或完整世界回放。
