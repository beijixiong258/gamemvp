## 世界背景与武器管制

常规世界以 1547 年、嘉靖二十六年为起点。传统刀剑、长柄兵器、弓弩及早期火器构成常规装备基础；后续科技研究可以提高材料、锻造、精密加工与生产水平，但不能在开局默认普及现代手枪、步枪、霰弹枪和弹匣供弹。

武器管制采用现代中国大陆式严格管制的世界观前提，技术年代与管理制度分别设定。刀具按具体形制和用途分类，普通工具与实战武器不能共用一个购买规则；枪械及弹药不设置普通人的自由购买渠道。详细分类、配用主体、许可与场所规则待世界制度完善后确定。

物品必须分别记录所有者、持有人、来源、持有资格和携带范围。职位、财富、好感或一次转赠均不自动产生配用权；获准持有也不等于能携入任意会面。机构配发物品可以归官署所有，人物只是领用人，离任、遗失与私自转手各有后续处理。

非法持有与流转可以作为游戏事件存在。实际违法、是否被发现、执行者是否被识别以及是否形成有效指控分别判断。非法取得不会削弱装备性能，也不会自动触发全世界知情。

店长的短剑和小绿人套装属于独立的跨时代彩蛋。取得孤品不解锁常规科技树，也不使普通工匠、商店或军械机构突然具备相同制造能力。

## 玩家操作与典型场景

### 从交谈发起行动

刺杀既可来自筹备，也可在正在进行的交谈、小会或人物事件中突然发起。玩家点击具体人物的【人物行动 → 刺杀】，或通过自由输入表达明确意图，进入相同的确认流程。

“我恨他”“我要清君侧”等表述不自动生成攻击、目标名单或伤亡。目标不明时先选择具体人物。确认前可以返回；只有正式提交后才消耗相应资源。已经完成的调查、交易和准备费用不会因放弃而退回。

确认面板显示目标、当前已装备物品、自身状态、已知现场风险、行动额度与体力成本。未知护卫、秘密立场和他人真实想法不能通过精确成功率泄露。携带什么装备、为什么能带入当前场合，必须在事发前已成立。

### 内廷决裂的完整推演

以未来官场中的虚构小会为例：玩家是大学士，与皇帝、宠臣魏某、同僚周某及现场护卫同处一室。亲信反戈的戏剧情境可以借鉴历史事件，但下面的目标与结果均是本局虚构分支。

| 步骤 | 玩家执行的操作 | 界面及结算 |
| --- | --- | --- |
| 1 参加与争论 | 接受邀请进入小会，阅读发言，输入反驳、请求说明或选择离席 | 保持普通交谈；争执本身不触发攻击 |
| 2 明确目标 | 点击魏某的人物卡，选择【刺杀】 | 展示目标及当前条件；可以返回 |
| 3 正式动手 | 查看装备、体力、已知风险，点击【确认动手】 | 占用主要行动，打开现场交锋面板，提交首个攻击动作 |
| 4 读取现场 | 查看本轮伤势、人物移动、护卫反应和实际剩余动作 | 其他人物已经获得反应机会；命中不等于死亡 |
| 5 决定是否继续 | 防守、停止抵抗、尝试撤离，或重新选取仍在场的目标 | 每个新攻击重新判断条件；不能继承已用掉的开场突袭加成 |
| 6 改变对象 | 若仍能行动且皇帝在场，可再次明确选择皇帝并确认 | 这是新的攻击选择，受当前伤势、装备和现场状态约束；不会自动演变为攻击所有人 |
| 7 请求协助 | 在状态允许时与周某交谈，请其转达陈述、协助救治或陪同接受调查 | 同意请求与实际履行分别记录；共同立场不等于支持刺杀 |
| 8 处理处境 | 请求救治、陈述经过、停止抵抗、接受调查，或在条件允许时离开 | 被控制时不能靠点击地图脱离；已死亡或失去行动能力者不再获得正常动作 |
| 9 应对余波 | 阅读有来源的通知与消息，回复周某、询问消息来源、提交实际持有的材料 | 伤亡、证据、传闻与正式裁判分别呈现；职位及政策进入各自流程 |

玩家可以停下来阅读界面，但不能连续点击而让其他人物没有反应机会。查看自身状态和已有记录不额外制造一个战斗动作；交谈、救治等现场行为是否占动作，需要按各自规则明确。

同一次事件允许产生“宠臣死亡、皇帝存活”“皇帝死亡、宠臣存活”“两人均死亡”“目标存活、玩家失败”等分支。两名目标死亡仍不等于政变成功；支持某项政策的同僚，可能反对玩家的行为，也可能只答应转达陈述。继任者甚至可能使玩家的政治处境更差。

### 其他四种场景

| 场景 | 玩家操作 | 必须保留的分支 |
| --- | --- | --- |
| 幕后委托 | 找具体 NPC 交谈，提出委托与条件，确认对方接受，支付实际费用，等待或询问报告；必要时提出撤销 | 接受、收款、执行、报告各自成立；可拒绝、反悔、背叛或谎报。已经发生的死亡不能因撤单而撤销 |
| 私人复仇 | 读取有来源的旧案消息，调查、质问、继续维持关系，或明确选择刺杀；事后再处理新证据与亲属反应 | 真相由本局事实决定，不能为了反转临时改写。道德值不直接锁定功能，“替天行道”也不自动加道德 |
| 证人遇害 | 作为涉案者作出选择，或作为调查者核对既有证言、材料和死亡事件 | 证人死亡只终止其后续活动，不删除已提交材料、他人记忆或独立证据；原案与死亡事件分别处理 |
| 玩家遇刺 | 接收有来源的警告，调查、求援、安排游戏内防护或缓和关系；遇袭时选择防守、应对或脱离 | NPC 必须有具体动机、资源和执行过程；玩家可能误判幕后人物。幸存后仍可追查、和解或进入裁判流程 |

委托不是一键成功购买。玩家可能收到虚假死讯，并在不知真相时作出新的发言或任官请求；这些行为会继续影响世界。NPC 对玩家采取同类行动时使用同一套人物、装备和结果规则，不依靠无来源的随机突然死亡制造主要难度。

## 战斗界面与装备生效

### 轻量回合面板

战斗从当前场景展开，暂采用轻量回合制。面板显示交锋轮次、自己的气血与体力、已装备物品、在场人物、目标、当前动作和成本。

可选动作包括【攻击】【防守】【使用道具】【更换装备】【装填或换弹】【尝试撤离】【停止抵抗】。玩家选择目标与动作后确认，程序结合其他人物动作结算现场变化。射击类装备显示实际剩余弹药、可用补给及装填进度。

自己的数值可以精确展示；其他人物默认只显示玩家能够观察到的伤势与已知装备。查看面板不能成为读取 NPC 隐藏属性、秘密支持关系或幕后委托人的入口。

**交锋轮与游戏日历回合分开。** 主动发起刺杀拟占一次主要行动，内部交锋继续支付各动作体力；点击一次攻击不推进十天。主要行动额度已经用完不应阻止玩家被袭击时正常防卫。整场冲突如何占用日历时间仍待定。

### 人物属性与装备栏

| 项目 | 设计职责 |
| --- | --- |
| 武艺 | 近战命中、操控与伤害发挥 |
| 射击训练 | 远程命中、操控及使用效率；最终字段与技能划分待定 |
| 身法 | 交锋先后、回避与脱离 |
| 体能与当前体力 | 体能影响身体上限，当前体力支付动作成本 |
| 气血与生命状态 | 承受战斗伤害，并独立记录存活、死亡及失去行动能力 |
| 健康与伤势 | 影响身体状态，不能与气血、体力混为同一个值 |

气血上限曾拟为“60＋体能”，属于待校准公式，需要与 1～100 武器评分统一验证。战后气血、伤势、弹药与装备状态持续保存，不因关闭面板或离开场景补满。战斗伤势与现有健康的映射另行确定。

装备栏拟区分武器、护具、随身装备与快捷道具。持有和穿戴分开；背包里放着一件护甲不代表已获得防护。护具需要记录覆盖部位，完整套装与单件装备的占位、互斥关系待细化。同一物品不能重复穿戴，两把武器的威力不会直接相加。

道具效果来自明确配置，品质颜色、名称和叙述不产生额外攻击力或必杀。换装、切换武器、使用恢复道具均拟占一个交锋行动。恢复体力不会复活人物。防守拟提供不依赖攻击体力的应对选项，是否附带少量体力恢复及具体数值待定。

## 交锋结算与成果判定

### 单次动作顺序

一次动作依次检查人物是否仍能行动、目标是否仍有效、实际装备与距离条件、所需资源，再确定命中、命中部位、防具覆盖、伤害和后续状态。目标已经死亡或脱离时，原动作不能照常执行；具体取消或改选规则待定。

每轮根据各人的选择和先手值执行动作。护卫的保护占用其动作，只有实际生效后才提供相应效果；旁观者不自动加入敌方。武器触及距离与场景空间独立检查，不能仅靠先手修正代替距离。

以下先手与命中数值仅作候选规则：

    先手值 = 身法 + 装备先手修正 + 随机数 0～20
    符合开场突袭条件时，首次攻击先手额外 +20

    命中率百分点 =
      60 + 0.5 ×（相关攻击技能 − 目标身法）
      + 装备命中修正 + 现场与状态修正
    最终命中率限制在 10%～95%

相关攻击技能按近战、射击等动作确定，不能把近战武艺统一套给所有火器。候选命中修正为开场突袭 +15 个百分点、目标有效防守 −20、攻击者过劳 −10、重伤 −15；这些修正及叠加方式仍需校准。

突袭必须由现场事实支持。熟悉、交谈或玩家自述“他毫无防备”均不直接成立。加成只用于首次实际执行的开场攻击，落空也会消耗；换目标、读回执或重试不能刷新。取消所有武器通用的突袭伤害 ×1.5。

### 无甲伤害与护甲伤害

先得到本次命中的无甲伤害，再进入对应类型的防护结算。武器威力是评分，不等于本次必定扣除同样多的气血。

近战无甲伤害需要结合武器、人物体能、武艺与状态；枪弹杀伤主要来自武器和弹药，射击训练主要影响命中与操作效率。不能继续为所有枪械套用“武器威力＋0.4×武艺”的旧式公式。

武器评分归一化以后，无甲伤害、气血、身体状态与随机浮动的完整换算公式尚未核定。后文“无甲伤害 80”是明确给定的算例输入，不代表威力 80 的每次命中都固定扣 80。

### 三个独立结果

| 维度 | 记录内容 |
| --- | --- |
| 目标 | 死亡、受伤存活、未受伤、脱离现场 |
| 自身 | 存活脱离、受伤、受到控制、死亡 |
| 身份与知情 | 谁目睹、谁认出执行者、谁知道委托、谁只是听说或怀疑 |

致命攻击将气血降至 0 时，草案判为死亡；体力归零仅表示力竭。非致命动作、失能阈值和伤势分级另行设计。人物死亡使用独立生命状态，不能把现有 MVP 的健康归零直接改成死亡。

结果可以是“目标死亡而玩家也死亡”“目标存活但玩家脱离”“目标死亡且玩家被当场辨认”。完成刺杀不会自动授予官职、继承财产、兑现政策、取消案件或获得道德奖励。

## 伤害类型与穿甲

### 三种伤害类型

| 伤害类型 | 动作示例 | 读取的防护 |
| --- | --- | --- |
| 切割 | 刀剑劈砍、战斧挥砍 | 防切割 |
| 穿刺 | 刀剑突刺、长枪、箭矢、子弹 | 防穿刺 |
| 钝击 | 棍棒、战锤、拳脚、枪托敲击 | 防钝击 |

伤害类型属于攻击动作，同一件武器可以有不同动作。剑的劈砍与突刺、短剑的射击与枪托敲击，分别使用各动作自己的威力、破防及体力成本。每次攻击先按一种主要类型处理，不再单列枪弹伤害、防弹属性或第四种穿甲伤害。

武器破防与防具对应防护均采用评分。破防 60 不代表忽略 60% 护甲；防护强度与覆盖范围也不能合并。

### 连续削减公式

先判命中，再判命中部位是否有有效防具覆盖，最后比较本次攻击的破防与该部位的对应防护。没有防护时取 0；已经确定命中位置后，不再随机一次“护甲是否生效”。

    穿透余量 = 本次攻击破防 − 命中部位当前的对应防护
    伤害通过系数 = clamp((穿透余量 + 20) ÷ 40, 0, 1)
    穿透伤害 = 本次无甲伤害 × 伤害通过系数

clamp 表示把结果限制在给定上下限内。系数是伤害保留比例，不是再掷一次穿甲骰子的概率。“±20”过渡区间及最终取整方式属于待校准参数，完全拦截时允许伤害为 0。

短剑射击的破防取 42，假设本次无甲伤害为 80：

| 命中部位防穿刺 | 通过系数 | 穿透伤害 |
| ---: | ---: | ---: |
| 0 | 100% | 80 |
| 20 | 100% | 80 |
| 35 | 67.5% | 54 |
| 42 | 50% | 40 |
| 55 | 17.5% | 14 |
| 65 | 0% | 0 |

这些是游戏评分算例，不对应现实材料或弹药试验。传统衣甲也必须按三类防护分别配置，不能为了临时对抗玩家而凭空提高普通 NPC 的防穿刺值。

未穿透时，可以按明确装备规则产生体力、姿态或耐久变化，但不能把已经拦下的伤害再次完整算成钝伤。防具先按当前状态承受本次攻击，再记录损耗并影响后续防护；耐用评分控制磨损能力，破防不直接等于每次扣掉的耐久点数。当前耐久、磨损公式及损坏阈值待定。

## 武器属性与价格

### 属性口径

| 属性 | 说明 |
| --- | --- |
| 威力 1～100 | 基础杀伤评分；100 不保证命中，也不保证秒杀 |
| 破防 1～100 | 对相应防护的克服能力，进入穿甲公式 |
| 耐用 1～100 | 抵抗磨损与损坏的能力，与当前耐久分开 |
| 命中修正 | 加减命中率的百分点，例如 65% 加 8 后为 73% |
| 先手修正 | 加减交锋排序值，不增加每轮行动次数 |
| 攻击体力修正 | 暂按攻击基础成本 12 点计算，−4 表示消耗 8，+6 表示消耗 18；装填另算 |

武器价值由技术、制造质量、产能、稀缺、来源和成交条件共同形成。高价刀剑不会提高持有者气血或凭空抵挡枪弹；低价但技术更先进的装备可以压过昂贵旧式名器。保留现代枪械相对传统冷兵器的杀伤优势，不用装填成本强行把技术差距抹平。

价格统一采用银本位显示：1 两白银＝1,000 文；未满 1,000 文用文，达到 1,000 文后用两白银，零头保留文。大额仍用白银，不自动改成黄金。下面全部是游戏报价草案，尚未与中后期收入、产量和完整战斗节奏校准。

| 武器 | 弹药或投射物 | 装填草案 |

| 火绳长铳 | 单发 | 射后装填占 2 次交锋行动，体力成本待定 |

装填过程中其他人物照常行动；装填可以被打断，已经完成的部分拟保留。空弹时射击不可执行，玩家选择装填、切换或其他动作。切换武器、重新装备和关闭战斗都不会补充弹药。

单次命中伤害与包含落空、换弹在内的平均输出分别评估。例如假设某武器连续射击 12 次、换弹耗 1 次行动，在其他条件不变时长期输出比例为 12÷13≈92%；这不是给短剑确定 12 发容量。短暂交锋可能根本遇不到换弹，其技术优势应当真实生效。

## 科技与获取条件

### 制造发展

| 方向 | 影响 |
| --- | --- |
| 材料研究 | 强度、韧性、重量与可采用的结构 |
| 锻造与处理工艺 | 锋利保持、抗损坏与性能稳定性 |
| 精密加工与配重 | 操控、命中修正与体力效率 |
| 检验与生产 | 良品率、制造周期、产量与价格 |

研究决定性能上限，制造条件决定能否试制和生产。研究完成还需要材料、设备、工匠与产能，不能让所有商店立即刷新同型号库存。新型定制品可以更昂贵，成熟工艺量产后同类产品也可以降价。

惊鸿、秋水是可重复制造的高阶工艺型号，性能与价格都应体现满工艺价值。镇岳、燧日是后期军事科研的试制项目，允许对传统江湖装备形成明显代差；军事科学院的机构、科技节点、出现年代与生产条件尚未具体设计。

### 获取与使用分开

玩家需要分别解决能否取得、能否熟练使用、能否带入当前场合。武器不必附加无关的角色等级锁；持有一件装备也不会直接增加武艺或射击训练。

官署佩刀按具体岗位权限、用途和批准领用，不能只看官品。工匠定制需确认方案、报价、材料、产能和交期，交付才生成持有关系；早期提出的 6～9 个游戏回合只是交期候选，不适用于所有订单。赠与、继承和人物转让均须有实际物品及明确交付，持有人死亡不会自动把装备放入玩家背包。

镇岳、燧日可经“样机流失”这类虚构涉案剧情进入玩家手中：介入事件、获得交涉机会、确认具体样机和配套物资、完成实际交易，再决定装备、使用或转手。每件样品保留身份和来源；调查能否追到玩家由实际信息传播决定，不因非法取得自动削弱性能，也不强加“实验品必定随机炸膛”。

后续成本可以来自真实补给、维护能力、生产瓶颈、机构追查及人际关系。取得样品不等于取得设计、材料与复刻能力。

## 店长彩蛋装备

### 短剑

名称采用“短剑·KRISS Vector”；Super V 为其系统名称。游戏内设为宁波未命名机关师店长的独有作品，与[镇店之宝合图](../../src/main/resources/images/equipment/unnamed-mechanist/masterpiece.png)对应。

威力确定为 80，破防暂取 42、耐用 80；命中 +8 个百分点、先手 +2、攻击体力修正 −4，即暂耗 8 点体力。最新拟价为 300,000 两白银，替代 80,000 两旧报价；高价体现孤品与独占供应，不继续按售价堆高伤害。

玩家操作为：找到店长并谈论镇店之宝 → 获得其出售意愿 → 确认报价并购买 → 实际交付后取得武器。普通商店、军科院供应目录、随机奖励和涉案流转均不另设短剑获取渠道。

配套 .45 ACP 弹药也只由店长接单现造。玩家下达数量订单，店长给出报价与交期；接受订单后开始生产，完成交付才增加弹药。付款不会立即补满，等待期间玩家正常活动。弹药单价、批量、交期、产能与具体弹匣容量待定。

店长保持隐士与私人经营身份，只卖有缘人，不参与政治、不接军工订单、不涉江湖争斗。有钱不保证她愿意出售，彩蛋能力不将她变成量产军械供应商；具体认可条件尚未确定。

### 小绿人套装

外观采用用户确认的俄军 6Б43／6Б45 系列绿数码重装，以 6Б45 重装版轮廓搭配俄式头盔、迷彩服、护具与军靴。保留织物、织带、扣具和 EMR 绿数码迷彩；明代特色放在陈列环境，不能改画成动力甲、外骨骼或金色封闭面罩。

游戏定位为店长独有的传说级彩蛋防具，完整穿戴且状态完好时，传统冷兵器造成 0 伤害，也不能通过反复攻击磨坏。以下面板是游戏草案，不代表现实装具的覆盖率或防护性能。

## 知情范围与长期后果

客观事件、人物知道的内容、人物相信的内容和裁判认定分开。亲历者只记其实际见闻，护卫可以认出执行者，受托者可能知道委托人，远方人物则可能只收到死讯。消息必须经过交谈、转达、报案、供述或调查等实际事件传播。

NPC 可以误信、包庇、诬告或说谎，社会关系也可在定罪前恶化；这些反应不能直接改写客观犯罪事实。认出某人的武器、听见动静或收到完成报告都不自动证明委托关系。

人物死亡保留身份与历史引用，并影响其后续对话、交易、行动、任职及提供服务的资格。已经存在的证据、他人记忆和因果关系继续保留；重要人物死亡后，服务中断、资产处置与岗位继任须各自处理。

玩家的自我解释与他人评价分别保存。无人知情时不自动全城敌视，后来出现的证据仍可改变关系。死者亲友、门生和同僚依各自经历反应，秘密可能成为人情、要挟或长期报复的来源。

司法沿用[经济与司法](经济与司法.md)的边界：调查、指控、事实认定与刑罚分开。玩家有罪时可执行处罚为罚钱、撤职、死刑；不能改成有期徒刑、强制等待等剥夺游玩时间的变体，也不能把原本应监禁的案件一律升级为死刑。玩家死亡结束当前人生，保留记录，由玩家自行读档。

## 后续接入与待定事项

AI 负责理解意图、人物动机与叙事，程序负责资格、资源、动作、伤亡、物品状态及事件提交。人物发言、委托报告、装备描述和自由输入不直接写成结算事实。

行动消耗、骰点、伤亡、弹药、耐久和事件应一起保存；同一动作重试返回原结果。叙事或记忆生成失败不撤销已提交事实，也不重新掷骰或复活人物。

中期先完成生命状态、主动刺杀、现场交锋、知情与追查的基本闭环；远期再扩展委托、组织继任、NPC 主动谋划和政治连锁反应。具体开放人生阶段不在本轮确定。

仍待细化的内容包括：

- 无甲伤害与气血的统一尺度、射击训练字段、伤势和非致命状态、命中部位与覆盖规则。
- 距离、移动、保护、防守、撤离、取消动作、现场交谈和整场日历成本。
- 护具部位、套装互斥、耐久损耗、修理及磨损后防护变化。
- 第 15 件武器的原型与出现年代，各科技节点、军事科研机构及生产条件。
- 各武器弹药成本与供应、短剑弹匣和换弹成本、店长订单批量与交期。
- 店长认可条件、小绿人具体部件、最终报价与中后期收入的经济校准。
- 委托违约、信息传播、调查证据、服务继任和死亡后的资产处置。

这些待定项不能由 AI 在运行时临时补成免费能力、隐含保底伤害或凭空物资。本次只记录设计方向与草案，不修改 MVP 配置、源码、版本或存档。
