# 政治书籍与任职阅读门槛

> MVP 后续设计。本阶段不加入本批书籍、官品阅读限制或任职必读检查。

## 一、设计规则

- 政治与经济经典作为穿越题材的趣味内容，供后期官员学习。
- 学习解锁与任职必读分开：达到规定官品或任职条件才能学习，申请目标职位或加官时再检查是否读完。
- 必读门槛集中在二品关键职位、内阁和一品加官，核心书单为 3～4 本，须全部读完。
- 以存档中的阅读完成记录为准，进度须达到 100。未完成则阻止任命、晋升或授衔；完成阅读仍须满足其他任职条件。
- 学习条件应支持在目标任命前完成书单，也应兼容跨品晋升。

| 书籍 | 游戏设计侧重 |

## 三、关键门槛草案

以下组合供后续定稿：

| 目标 | 必读书目 |
| --- | --- |
| 户部尚书 | 《君主论》《资本论》《国富论》 |
| 内阁大学士 | 《君主论》《共产党宣言》《国富论》 |

| 从一品、正一品加官 | 上述四部经典 |

同一本书的完成记录可用于多个目标，调任或免职不清除阅读成果。任命界面列出尚未读完的必读书。

## 四、规则衔接与待定项

官品、岗位与加官复用[官职设计](./官职与爵位.md)：

- 官品使用整数 `rank`；岗位与加官使用稳定代码。
- 户部尚书同时匹配 `OFFICIAL_SHANGSHU` 与户部的 `organizationId`。
- 内阁分别匹配 `OFFICIAL_STATECOUNCILER`、`OFFICIAL_VPM`、`OFFICIAL_PM`，阅读要求不改变职位与官品分离的规则。
- 一品加官按目标 `HonoraryTitle` 的品级 `17／18` 匹配；爵位不能替代阅读要求。
- 必读条件引用书籍稳定编码，复用阅读完成记录；AI 叙事不作为完成依据。

实施前确定各书的学习解锁品级、最终必读组合、当代书目及其替换关系。具体数值和字段扩展届时再定。
