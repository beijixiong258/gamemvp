以下内容尚未实现，MVP 边界见[玩法与范围](../MVP/玩法与范围.md)，官品、机构、任职、授权和待遇的具体设计见[官职与爵位](官职与爵位.md)。

## 世界、人物与权限

人物可同时拥有文豪、艺术家、商人等领域能力与成就，加入新领域不清空旧能力。AI 还可参考立场、承诺、公开形象和经历；立场转变按情境评价，不固定扣分。

大多数人口只作统计，路人可临时生成，有持续关系或重要影响者才长期保存。世界事实与人物记忆分开：数据库记录世界，记忆只保存本人经历、知道或重视的内容；检索后续结合地点和当前任务，语义检索与完整世界记忆另行设计。

人物可在多个组织任职，称号或成就不自动授行政权。权限明确事项和辖区，可覆盖下级，不能自动扩大到同级或上级；差遣可额外授权，被架空可保留职位而收回权限。影响力综合官阶、权限、关系、声望和资源，不代替权限检查。

皇帝或同等授权者可授予、收回、调整权限，支持摄政与共治。官职可改名、重组或废除，仍组合已有权限，不凭名称创造底层规则。完整地图、商业、政策、战争、NPC 自动生活以及县试后的府试、院试等人生阶段后续展开。

## 政治书籍与任职门槛

政治与经济经典作为穿越趣味内容。学习解锁与任职必读分开：达到官品或其他条件才能学习，目标任命、晋升、授衔前再查是否全部读完。核心门槛集中在二品关键职位、内阁和一品加官，书单为 3～4 本；学习条件应允许提前完成及跨品晋升。

| 候选书目 | 设计侧重 |
| --- | --- |
| 《君主论》 | 权力运作、统治与政治判断 |
| 《共产党宣言》 | 制度、阶层与政治组织 |
| 《资本论》 | 经济结构、生产与利益关系 |
| 《国富论》 | 产业、贸易、税收与财政 |
| 当代政治与治理读物（“地球 OL 国服现版本”） | 关键职位专用，书名与版本待定 |

| 目标（草案） | 必读组合 |
| --- | --- |
| 户部尚书 | 《君主论》《资本论》《国富论》 |
| 内阁大学士 | 《君主论》《共产党宣言》《国富论》 |

| 从一品、正一品加官 | 上述四部经典 |

仅认存档中进度达到 100 的完成记录；未完成阻止任命，完成仍须满足其他条件。同一完成记录可用于多个目标，调任免职不清除，界面列出缺书。AI 叙事不作完成依据。

官品使用整数 `rank`，书籍、岗位和加官使用稳定代码。户部尚书匹配 `OFFICIAL_SHANGSHU` 与户部 `organizationId`；内阁分别匹配 `OFFICIAL_STATECOUNCILER`、`OFFICIAL_VPM`、`OFFICIAL_PM`；一品加官按 `HonoraryTitle.rank=17/18` 判断，爵位不能替代。学习解锁品级、最终组合、当代书目替换关系及字段扩展待定。

## 随机种子

当前有效行动直接生成并保存骰点，重传返回原结果；随机种子拟用于重现骰点：

- 每局保存一个种子，读档沿用；是否允许玩家自选待定。
- 由存档种子、稳定行动编号、用途及算法版本确定骰点；阅读和考试分用途，多次掷骰加固定子序号。
- 重试次数、模型调用次数和当前时间不改变同一行动的骰点。
- 已完成行动保留原骰点，算法更新不重算；具体算法、版本字段及旧存档补种子方式待定。

相同种子只在规则与输入相同时重现骰点，不保证不同操作顺序的人生或 AI 回答相同，也不承担防作弊、复杂并发和完整世界回放。
