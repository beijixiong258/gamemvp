# 经济与司法

> 后续设计，尚未实现。MVP 依然只包括原有书生线；本文件不改变现有钱包、教材、清茶、考试、重病与无死亡的玩法边界。中央权责见[中央会议与行政流程](中央会议与行政流程.md)。

## 收入与资产

经济参考明代背景并服务于游戏性，不把当代 PRC 的工资、财政和行政数值直接套入。岗位工资、兼任待遇、爵禄和差遣收入的已有字段方案见[官职与爵位](官职与爵位.md#四爵位与俸禄)。

个人工资、家产、可支配现金、经营收入、往来馈赠及非法收入应分别记录。`rank` 只影响基本工资与交互身份；权限来自岗位及授权。核定年收入不是钱包现款，也不是财富总额；应付、实付与欠付要分开。国库预算、批准拨款与实际支付也要分开，不能批准一次就制造资金。

每笔资产变化需要明确来源：实际交易对手、库存、已定义生产或薪酬规则、合法发放事件等。政治表态、私人许诺、人物声望、叙述以及模型自称“已经结算”都不构成资产来源。收入的周期、税基、物价、国库规模及影响力费用尚未确定，不把格式示例当成平衡数值。

## 历史人物经济档案

严嵩等关键人物需要独立经济档案，至少区分任职收入、本人可动用现款、家庭／田产等资产、收支来源、利益关联与公众认知。历史记载中的家产、抄没财物或某个家庭成员的资产不能直接全算进角色某年钱包。

每条历史数据保留出处、对应年份、所有者、计量单位与确定性；没有可靠数值时保留范围或待考，具体游戏初值以后统一校准。玩家和 NPC 各自能知道多少由公开消息、亲历、调查或可信报告决定，角色传记不能自动公开隐秘财富，更不能泄露未来抄家等结果。

本轮尚未核定严嵩等人的具体资产、收入数值与经济平衡表，不编造其历史财富数字。后续整理史料并设计数值时，再补到人物经济档案及对应资源定义。

## 司法与刑法

刑法参考资料可以保留有期徒刑等历史刑罚，NPC 与玩家的适用规则分开。提供给审理玩家案件的法官智能体的上下文和可选刑罚必须过滤；最终程序再次检查，不能仅靠提示词防止判错。

玩家有罪时可执行的处罚范围为罚钱、撤职、死刑；无罪及不成立的案件可以不处罚。不能判玩家有期徒刑，也不能换成强制等待、流放、劳役等同样剥夺游玩时间的变体。死刑使游戏结束，玩家自行读档重来（SL）；书生 MVP 不因此增加死亡玩法。

不能把“过滤掉监禁”解释为原判监禁自动改判死刑。替代处罚需要明确的游戏法条与量刑设计；不能由模型随意提高刑罚。罚款有无资金、撤职是否存在有效任职及死刑终局都需要合法案件与裁判依据。

调查、指控、事实认定、任免和刑罚分别处理。“有人弹劾”“大家怀疑”“政治会议同意罢免”不等于已证明犯罪，也不等于已经获得刑事裁判权限。NPC 可以偏信、包庇或诬告，但其言论和动机不能直接写成客观犯罪事实；具体司法岗位权限、复核程序与法条另行设计。

玩家刑罚过滤是后续司法系统的硬约束，相关刑法参考文献、完整法条和 NPC 刑罚表仍待整理。本轮只记录设计决定，不声称已经实现司法业务。
