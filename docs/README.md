## 文档分工

玩法说明只写玩家会遇到什么；规则文档统一维护公式和数值；开发手册解释代码、配置与数据库。已确定的内容直接写成规则，未确定的内容放入待办或后续设计。

接口签名以源码为准，初始配置以资源文件为准，已有存档的数据以数据库为准。修改其中一项时，同步更新对应文档。
