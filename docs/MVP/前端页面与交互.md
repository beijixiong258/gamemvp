# MVP 前端页面与交互

源码位于 [src/frontend](../../src/frontend/README.md)。界面围绕[书生线流程](玩法与范围.md)组织开局、场景行动、考试和结果，页面状态以服务端存档为准。

## 首页

首页提供新开局和读取存档入口。桌面布局左侧为版本介绍，右侧为存档列表；主标题按介绍区宽度调整字号，保持单行。展示文案如下：

| 位置 | 文案 |
| --- | --- |
| 品牌标识 | 印章“书”与“豪杰成长计划plus” |
| 主标题 | 豪杰的故事由你来书写 |
| 版本介绍 | 当前为最小交付版本（MVP），先开放书生线。你可以从入学开始，体验学习、人物互动和考试，进度会自动保存。 |
| 新开局按钮 | 启程 · 新的人生 |
| 存档区小字／标题 | 存档／读取存档 |
| 页脚介绍 | 《豪杰成长计划plus》是一款人生模拟游戏，你可以安排角色的行动、培养能力，并与其他人物互动。 |

首页不另加时代标签或氛围短句。存档卡片显示姓名、年龄、游戏年份、已有功名和建档日期，不显示“求学中”“待阶段考试”“待县试”“本局已结束”等流程状态标签；实际流程仍由服务端状态决定。

## 主界面

```text
┌──────────────────────────────────────────────────────┐
│ 头像、姓名、年龄、地区                 当前位置        │
│ 日期、健康、疲劳、钱包、学识           子地点列表      │
│                                       返回上级        │
│ 地点说明、行动与实际反馈                               │
│ 人物列表    其它地点                      自定义行动   │
└──────────────────────────────────────────────────────┘
```

左上人物区、右侧地点树、底部“人／路／行”圆形入口沿用草图。日期按年、月、月内回合显示，每月三回合。头像与姓名可展开属性、书生能力及身份详情；未知身份不推导虚构值。

行政地区与具体房间分别显示。同县地点切换和浏览器前进后退只改变浏览位置，不耗回合；待考、已结束存档分别优先进入考试、结果页。

## 地点与人物

```text
当前县城
├─ 家中庭院 → 卧室、书房、主卧
├─ 知微私塾 → 讲堂、藏书阁
├─ 陆记书铺
└─ 县衙（尚未开放）
```

现代“学校、教室、图书馆、政府”对应知微私塾、讲堂、藏书阁、县衙。私塾为六岁启蒙机构，不授官学身份。官署名称见[官职与爵位](../后续设计/官职与爵位.md#27-官署名称与地图入口)。

| 地点 | 场景代码 | 行动与固定人物 |
| --- | --- | --- |
| 县城、家中庭院、私塾庭院 | 无 | 导航容器；家中庭院为新局入口，可回看童年 |
| 卧室 | `SCENE_JIA_WOSHI` | 休息、自定义行动，无常驻 NPC |
| 书房 | `SCENE_JIA_SHUFANG` | 普通阅读、父亲对话、自定义行动 |
| 主卧 | `SCENE_JIA_ZHUWO` | 父母房间，母亲常驻，家庭对话与自定义行动 |
| 讲堂 | `SCENE_SISHU_JIANGTANG` | 窦苞、嘉豪；领教材、阅读、练习、读书体会、对话、阶段考试 |
| 藏书阁 | `SCENE_SISHU_CANGSHUGE` | 沈砚；书目、普通阅读、对话、自定义行动 |
| 陆记书铺 | `SCENE_JISHI` | 陆掌柜；付费书和清茶交易、对话、自定义行动 |
| 县试考场 | `SCENE_XIANSHI` | 县试流程，考官不开放普通闲聊 |
| 县衙 | 无 | 显示未开放，不提交行动 |

导航容器的人物列表按实际房间分组，选择后先进入对应房间；自定义行动须明确选择具体房间或书铺。县试不能从地点列表随时进入。后端独立校验场景许可与人物在场关系；旧 `SCENE_JIA`、`SCENE_SISHU` 仅保留历史兼容。

| 人物 | 固定身份与职责 |
| --- | --- |
| 窦苞／`NPC_DOUBAO` | 成年女性塾师，名字谐音“豆包”；温和、善用生活比喻、偶有俏皮，负责教学、体会出题评阅及七本免费教材 |
| 嘉豪／`NPC_JIAHAO` | 年龄与玩家相近的同窗，交流求学与共同经历 |
| 沈砚／`NPC_GUANSHU` | 成年男性管书人，耐心、爱书、记性好；介绍书目和阅读条件，不发教材或免除门槛 |
| 父亲、母亲 | 沿用家庭身份，分别关注生计前途、身体与日常生活 |
| 陆掌柜 | 付费书与清茶交易、日常交谈 |
| 县试考官 | 由考试流程评价答卷 |

窦苞使用姓名拼音编码 `NPC_DOUBAO`；旧存档准备内容时沿用原人物 ID 更新编码，不额外生成第二位教师。女性身份不因“先生”称呼改变，不写成现实 AI 产品。外形参考豆包头像：齐颈深色短发、侧分刘海、大眼睛、温和笑容；穿青绿交领衫、米白内领和素色长裙，持靛蓝线装书，保持成年塾师气质，不加官服补子或宫廷首饰。

固定人物按场景配置驻留，动态人物按实际所在房间显示，不模拟后台作息。人物列表只展示当前有效身份，到期人物退出日常列表；活跃对话保护双方。动态人物可以从短暂偶遇发展为长期往来，原 ID 和身份延续，不因刷新重新生成。人物不会自动知道未参与的私人对话。名字、身份分别显示。藏书阁领取教材明确引导到讲堂，沈砚不冒用窦苞的交易权限；书房与藏书阁阅读共用正式阅读结算。

## 页面与面板

| 页面／面板 | 内容与操作 |
| --- | --- |
| 存档、创建人物 | 新开局、读档；姓名、年龄、年份、已有功名和创建时间，不显示流程状态标签；选择博罗或海丰，六岁开始 |
| 人物、行囊、记事 | 钱包、健康、疲劳、五项属性、五项书生能力、总学识、物品数量、童年及人生节点；行囊按实际用途提供“使用一份” |
| 书目 | 搜索与持有／免费／付费筛选；品质、价格、进度、学识、不可读原因；领书、购买、普通阅读、读书体会；读满标记“已完成”，阅读按钮禁用，不再显示写体会入口 |
| 读书体会 | 服务端题目、输入草稿、评分、点评与实际进度变化；失败保留原文 |
| 对话 | 双方原文、已完成轮数、本轮真实交易；只能向当前供应者获取物品，不代向旁人下单；发送、收起、主动结束；最多五轮，以服务端结束状态为准；历史发言保留当时姓名，人物退出日常列表后仍可识别 |
| 自定义行动 | 明确发生地点，提交原文后显示实际反馈与结算；新人物和物件只在服务端确认后出现 |
| 身边小物 | 当前房间有效场景物件的名称和说明；拾取后从场景移到行囊，原身份保留，不消耗回合 |
| 书铺杂物 | 展示清茶、价格、实际可购买状态及资金等受限原因；购买和使用不消耗回合 |
| 考试 | 题目、角色思路、亲自作答或系统代行；阶段考完成后继续求学，县试后进入结果 |
| 结果 | 县试成绩、答卷与评价、历次考试、关键经历；返回存档或另开一局 |

免费教材每人物每种限领一次，书目显示真实领取与阅读条件，属性门槛使用“智力、识字、文章”等中文名称；清茶供应由服务端返回实际可购买状态，资金不足时说明原因。疲劳为 0 时行囊禁用清茶并显示“此刻精神充足”，不消费物品。动态小物保留名称和说明，不出现凭模型文字生成的增益按钮。

写入等待期间禁止重复提交，成功后刷新状态。超时复用原请求编号和正文，状态冲突时重新读档；收起面板保留草稿，收起对话不发送结束请求。主动结束只总结已有交谈，不发送或记住输入框中尚未提交的草稿。重病提供继续休养入口，由后端决定实际回合与考试触发。恢复细节统一见[前端说明](../../src/frontend/README.md#请求恢复)。

## 视觉与操作

固定背景和独立人物／装备图统一存于 [images](../../src/main/resources/images/README.md)，运行时不生成图片。采用暖米白、青绿、木色的淡彩水墨风格；背景不画死人物、按钮或文字，中央面板保证文字对比度。

桌面保持草图区域关系，长文本可滚动；窄窗口按顺序排列人物、地点和内容。弹层支持键盘焦点、Esc 收起及返回原按钮，入口有文字说明；图片裁切不改变点击区域。
