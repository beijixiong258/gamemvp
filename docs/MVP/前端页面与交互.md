# MVP 前端页面与交互

源码位于 [src/frontend](../../src/frontend/README.md)。界面围绕[书生线流程](玩法与范围.md)组织开局、场景行动、考试和结果，页面状态以服务端存档为准。本文的页面、按钮与接口反馈说明均描述**当前实现**。正式术语和规则状态统一见[术语与规则状态](规则与数值.md#术语与规则状态)，引号中的按钮文字保留当前界面文案。

## 行动与回合的实现状态

系统操作、以身入局是操作方式的概念分类，不作为按钮名称。系统操作按角色能力与规则执行，操作名保留原名，包括阅读、练习文章、休息、考试；以身入局由玩家亲自提供内容，操作名加“（手动）”，包括阅读（手动）、考试（手动）。两类方式不按是否调用 AI 划分：考试仍调用 AI，但按两种考试统一的基础成本结算，不另加 AI 费用。人物对话、自定义行动继续使用各自规范术语，不在本节强行归类。

书籍学习的两个具体玩法名为阅读、阅读（手动）；阅读（手动）属于以身入局，分为生成阅读题目和提交阅读回答。游戏回合表示游戏时间，对话轮次表示一场人物对话中的交互进度。

**界面命名：** 正式名称已统一为“阅读”“阅读（手动）”“考试”“考试（手动）”；业务代码与 API 标识保留。

**当前实现：** 阅读、提交阅读回答、练习文章和休息共享本游戏回合一次主要行动额度，完成后不自动推进时间。主界面显示年月、月内回合与主要行动“已用／未用”，由“结束回合”推进时间，可以空过，不自然恢复体力。生成阅读题目不占主要行动额度；人物对话与自定义行动可在主要行动后继续进行，均不自动推进游戏回合。

成本直接使用服务端详情：两种阅读都只按书籍 `fatigueCost` 消耗体力，练习文章消耗 8 点；自定义行动、对话回复和主动结束各消耗 15 点，两种考试交卷统一消耗 5 点。阅读（手动）出题免费、不占主要行动额度，但须主要行动未用且体力足以支付本书阅读成本；提交回答只扣书籍成本并占主要行动。题目仅本回合有效，结束回合前会显示失效提醒。童年往事和考试思路首次生成、缓存复用均免费。

人物状态栏与人物详情显示后端返回的当前 `stamina` 和动态 `maxStamina`，长期属性“体能”单独展示。“疲劳”用于行动消耗展示：实际消耗显示“疲劳消耗 X 点体力”，恢复显示“恢复 X 点体力”，零变化显示“体力无变化”。

**体能与体力上限：** 已实现体能 0～100 经 `k=0.10` 的归一化 sigmoid 映射到 50～150 点整数上限，结果向下取整并保障端点；体能增长只增加上限，不补当前体力。前端直接展示服务端计算结果，完整规则见[体能与体力上限](规则与数值.md#体能与体力上限)。

**体力使用边界：** 当前体力不足以支付动作时禁用对应消耗按钮并说明成本，不允许透支；休息、查看和免费离开对话仍有入口。当前体力不高于 20 点时显示过劳，20 点进入、21 点不进入，使用绝对点数。学习效率与过劳伤害由后端结算，前端不重复计算。

休息最多恢复 20 点体力和 5 点健康，体力不超过动态上限，健康只恢复至 75 点，已有更高健康值保持不变。人物详情提示健康达到 50 点时没有健康带来的学习惩罚，低于 50 的曲线由后端计算；75 以上健康的未来伤害韧性不作为本轮已实现效果展示。体力恢复类消耗品单次最多恢复 20 点，具体效果使用物品说明。

## 首页

首页提供新开局和读取存档入口。桌面布局左侧为版本介绍，右侧为存档列表；主标题按介绍区宽度调整字号，保持单行。展示文案如下：

| 位置 | 文案 |
| --- | --- |
| 品牌标识 | 印章“书”与“豪杰成长计划plus” |
| 主标题 | 豪杰的故事由你来书写 |
| 版本介绍 | 当前为最小交付版本（MVP），先开放书生线。你可以从入学开始，体验学习、人物互动和考试，进度会自动保存。 |
| 新开局按钮 | 启程 · 新的人生 |
| 存档区小字／标题 | 存档／读取存档 |
| 页脚介绍 | 《豪杰成长计划plus》是一款人生模拟游戏，你可以安排角色的行动、培养能力，并与其他人物互动。 |

首页不另加时代标签或氛围短句。存档卡片显示姓名、年龄、游戏年份、已有功名和建档日期，不显示“求学中”“待阶段考试”“待县试”“本局已结束”等流程状态标签；实际流程仍由服务端状态决定。

## 主界面

```text
┌──────────────────────────────────────────────────────┐
│ 头像、姓名、年龄、地区                 当前位置        │
│ 日期、健康、体力、钱包、学识           子地点列表      │
│                                       返回上级        │
│ 地点说明、行动与实际反馈                               │
│ 人物列表    其它地点                      自定义行动   │
└──────────────────────────────────────────────────────┘
```

左上人物区、右侧地点树、底部“人／路／行”圆形入口沿用草图。日期按年、月、月内游戏回合显示，每月三个游戏回合。头像与姓名可展开属性、书生能力及身份详情；未知身份不推导虚构值。

行政地区与具体房间分别显示。同县地点切换和浏览器前进后退只改变浏览位置，不耗游戏回合；待考、已结束存档分别优先进入考试、结果页。

## 地点与人物

```text
当前县城
├─ 家中庭院 → 卧室、书房、主卧
├─ 知微私塾 → 讲堂、藏书阁
├─ 陆记书铺
└─ 县衙（尚未开放）
```

现代“学校、教室、图书馆、政府”对应知微私塾、讲堂、藏书阁、县衙。私塾为六岁启蒙机构，不授官学身份。官署名称见[官职与爵位](../后续设计/官职与爵位.md#27-官署名称与地图入口)。

| 讲堂 | `SCENE_SISHU_JIANGTANG` | 窦苞、嘉豪；领教材、阅读、练习文章、阅读（手动）、人物对话、阶段考试 |

导航容器的人物列表按实际房间分组，选择后先进入对应房间；自定义行动须明确选择具体房间或书铺。县试不能从地点列表随时进入。后端独立校验场景许可与人物在场关系；旧 `SCENE_JIA`、`SCENE_SISHU` 仅保留历史兼容。

| 人物 | 固定身份与职责 |
| --- | --- |
| 窦苞／`NPC_DOUBAO` | 成年女性塾师，名字谐音“豆包”；温和、善用生活比喻、偶有俏皮，负责教学、生成阅读题目、评阅玩家提交的手动阅读回答，以及发放免费教材 |
| 嘉豪／`NPC_JIAHAO` | 年龄与玩家相近的同窗，交流求学与共同经历 |
| 沈砚／`NPC_GUANSHU` | 成年男性管书人，耐心、爱书、记性好；介绍书目和阅读条件，不发教材或免除门槛 |
| 父亲、母亲 | 沿用家庭身份，分别关注生计前途、身体与日常生活 |
| 陆掌柜 | 付费书与清茶交易、日常交谈 |
| 县试考官 | 由考试流程评价答卷 |

窦苞使用姓名拼音编码 `NPC_DOUBAO`；旧存档准备内容时沿用原人物 ID 更新编码，不额外生成第二位教师。女性身份不因“先生”称呼改变，不写成现实 AI 产品。外形参考豆包头像：齐颈深色短发、侧分刘海、大眼睛、温和笑容；穿青绿交领衫、米白内领和素色长裙，持靛蓝线装书，保持成年塾师气质，不加官服补子或宫廷首饰。

固定人物按场景配置驻留，动态人物按实际所在房间显示，不模拟后台作息。人物列表只展示当前有效身份，到期人物退出日常列表；活跃对话保护双方。动态人物可以从短暂偶遇发展为长期往来，原 ID 和身份延续，不因刷新重新生成。人物不会自动知道未参与的私人对话。名字、身份分别显示。藏书阁领取教材明确引导到讲堂，沈砚不冒用窦苞的交易权限；书房与藏书阁阅读共用正式阅读结算。

## 页面与面板

| 页面／面板 | 内容与操作 |
| --- | --- |
| 存档、创建人物 | 新开局、读档；姓名、年龄、年份、已有功名和创建时间，不显示流程状态标签；选择博罗或海丰，六岁开始 |
| 人物、行囊、记事 | 钱包、健康、体力、五项属性、五项书生能力、总学识、物品数量、童年及人生节点；行囊中的书籍与书目共用阅读状态卡片，其余物品按实际用途提供“使用一份” |
| 书目 | 搜索与持有／免费／付费筛选；品质、价格、进度、学识、完整成长、不可读原因；统一显示“可阅读／条件不足／已完成”，按状态提供获取与阅读入口 |
| 阅读（手动） | 生成阅读题目后填写草稿，再提交阅读回答；显示服务端题目、评分、点评与实际进度变化，失败保留原文 |
| 人物对话 | 双方原文、已完成对话轮次、本轮真实交易；发送或主动结束消耗体力，收起保留会话；“离开对话（不结算）”免费，保留已完成交易；每场最多五个对话轮次，以服务端结束状态为准；历史发言保留当时姓名 |
| 自定义行动 | 明确发生地点，提交原文后显示实际反馈与结算；新人物和物件只在服务端确认后出现 |
| 身边小物 | 当前房间有效场景物件的名称和说明；拾取后从场景移到行囊，原身份保留，不消耗游戏回合 |
| 书铺杂物 | 展示清茶、价格、实际可购买状态及资金等受限原因；购买和使用不消耗游戏回合 |
| 考试 | 题目、免费角色思路、考试或考试（手动）；入场补满体力后确定本场状态，两种交卷统一消耗 5 点体力。手动答卷为评分主要依据，答案评分 0～100、合格基准 60，再按本场合格线校正；正式结果读取后端最终成绩与通过状态；阶段考试后继续求学，县试后进入结果 |
| 结果 | 县试成绩、答卷与评价、历次考试、关键经历；返回存档或另开一局 |

书目和行囊遍历服务端完整书目，新增书籍自动进入列表，不固定总数、价格或成长；复用同一书籍卡片，以后端 `readable/completed/blockedReasons` 为准。在任何地点都显示真实进度、读满成长及“智力需达到 30，当前为 25”等具体缺项；条件不足时禁用阅读，不显示阅读或阅读（手动）的导航入口。可读书在允许的房间直接操作，其余地点提供导航。已完成书显示“已完成”，不再提供阅读或阅读（手动）；不支持阅读（手动）的书有阅读说明。导航不会改变阅读条件，也不消耗游戏回合。

书籍学习成功后显示实际增加的属性和书生能力，属性达到 100 时只显示实际到账量。进入旧存档时，内容补齐接口返回本次实际补发成长，有补发才显示“已补齐阅读成长”。相同配置下再次进入不重复发放，后续成长调参由后端按历史额度核算；缺少必要历史数据时显示服务端错误并禁止继续写入。具体公式与免费解锁路线见[规则与数值](规则与数值.md#每本书的完整成长)。

免费教材每人物每种限领一次，书目显示真实领取与阅读条件，属性门槛使用“智力、识字、文章”等中文名称；清茶供应由服务端返回实际可购买状态，资金不足时说明原因。体力充足时，行囊禁用清茶并显示“此刻体力充足”，不消费物品。新增动态小物使用固定普通物件模板，已有实例保留名称和说明，不出现凭模型文字生成的增益按钮。自定义行动显示经过叙述与程序结算结果；人物对话的发言不作为付款或持有凭证。

写入等待期间禁止重复提交，所有写请求成功后刷新详情，包括免费生成题目、思路和童年往事，以同步最新状态。超时复用原请求编号和正文，状态冲突时重新读档；收起面板保留草稿，收起对话不发送结束请求。主动结束只总结已有交谈，不发送未提交草稿；免费离开不做成长结算。活跃对话须先结束或离开，才能结束游戏回合。重病提供“结束回合，继续休养”，后端推进剩余强制休养并处理考试暂停，不能用普通休息绕过。恢复细节统一见[前端说明](../../src/frontend/README.md#请求恢复)。

## 视觉与操作

固定背景和独立人物／装备图统一存于 [images](../../src/main/resources/images/README.md)，运行时不生成图片。采用暖米白、青绿、木色的淡彩水墨风格；背景不画死人物、按钮或文字，中央面板保证文字对比度。

桌面保持草图区域关系，长文本可滚动；窄窗口按顺序排列人物、地点和内容。弹层支持键盘焦点、Esc 收起及返回原按钮，入口有文字说明；图片裁切不改变点击区域。
