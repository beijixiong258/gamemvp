# MVP 待办事项

> 这里集中记录完成情况和未定问题。已经确定的玩法见[玩法与范围](./玩法与范围.md)，数值见[规则与数值](./规则与数值.md)。

## 一、已经接通的后端功能

- 新建存档、存档列表、读档、出生地选择及固定 NPC 生成。
- 领取和购买书籍、背包、阅读进度与总学识。
- 读书、练习、休息、自由行动和人物对话。
- 科举类书籍的以身入局读书：缓存题目、提交体会、AI评分与阅读结算，特殊书籍由开关限制。
- 阅读与考试掷骰、重病休养、四次考试的系统代行。
- 考试思维提示、玩家亲自作答与 AI 内容评价、系统代行 AI 答卷、两种作答方式的考试总结。
- 同一请求重复发送时返回原结果，避免重复扣款、发书或增加属性。
- 独立生成六岁入学前的童年背景，保存后复用；开局与初始数值不依赖模型。
- 对话最多五轮，由 AI 返回结束标志，可按语义提前结束；第五轮未结束的模型结果被拒绝，可重试。
- 已结束对话及重要经历生成参与者的压缩记忆，正文保存为 JSON 文件，数据库保存索引；自由行动与对话按人物读取不超过 5000 字的记忆上下文。

这些是后端能力，完整页面体验仍待完成。考试接口调用方式见[接口与方法](../开发者手册/接口与方法.md#考试调用)。

## 四、后续设计和已知限制

官职、称号、学位取得规则、其他领域、NPC 自动行动和完整世界模拟属于后续扩展，见[游戏总览](../游戏总览.md)及[后续设计目录](../../README.md#mvp-之后的设计)。身份展示字段不会自动授予实际职位或权限。

公共装备定义采用“先查询、再插入”。多个存档同时首次初始化时，仍可能发生唯一编码冲突，暂不增加全局锁和复杂重试。

记忆只来自已提交的结束对话和人生节点，失败后在相关调用中少量补齐；不保证模型失败时立即具有完整历史。记忆 JSON 属于运行数据，需要与对应数据库索引一起保留，改动静态资源不会重写已保存记忆。

旧版本若已把玩家节点考试错记到 NPC 名下，可能留下缺失的玩家待考记录或不正确的存档阶段。代码不自动改写历史考试及已保存的请求结果；此类存档需先核对记录，再确定修正办法。

已有库的结构和内容维护见[数据结构与升级](../开发者手册/数据结构与升级.md#十数据库初始化与维护)；修改建表脚本或资源文件不会自动更新已有数据。
