# MVP 玩法与范围

> 本文写首版目标；已完成与待完成内容见[待办事项](./待办事项.md)，计算方法见[规则与数值](./规则与数值.md)。

## 一、一局游戏怎么玩

填写角色名、选择出生地 → 六岁入学 → 领取或购买书籍 → 读书、练习、休息、自由行动或对话 → 参加阶段考试 → 十六岁县试后结束。

每次新开局建立独立存档，进入游戏时可以新建或读取旧存档。固定行动不依赖 AI；自由行动、人物对话、考试思路、答案评价及答卷总结需要 AI。

## 二、开局背景

开局是 1547 年（嘉靖二十六年），角色六岁，不逐年模拟零至五岁。家庭背景为家中有一定田产和积蓄，能够供角色入塾读书；初始数值见[开局与时间](./规则与数值.md#二开局与时间)。

1547 年对应夏言最后一次执政阶段的倒数第二年；他于嘉靖二十四年九月复入内阁，嘉靖二十七年正月罢职。历史只提供开局背景，之后可以因玩家行动而改变。[《明史·世宗二》](https://zh.wikisource.org/zh-hans/%E6%98%8E%E5%8F%B2/%E5%8D%B718)

首版使用广东的广州、惠州及五个县作为简化地图，只允许在博罗县或海丰县出生。广州及其下属地区先作为背景，地区关系见[数据结构与升级](../开发者手册/数据结构与升级.md#三地区关系)。

## 三、场景与行动

| 场景 | 用途 |
| --- | --- |
| 家中 `SCENE_JIA` | 家庭互动、休息、自由行动 |
| 私塾 `SCENE_SISHU` | 领教材、读书、练习、请教、阶段考试 |
| 县试考场 `SCENE_XIANSHI` | 十六岁县试 |
| 集市 `SCENE_JISHI` | 与书商互动、买书 |

固定行动包括读书（`READ_BOOK`）、练习文章（`PRACTICE_WRITING`）和休息（`REST`）。它们与自由行动都会消耗回合；查看页面、进入场景、领取或购买物品、普通对话不消耗回合。生病时会强制经过休养回合。

自由行动接受玩家原文，AI 给出影响，程序计算实际结果；行动中也可以完成领取或购买。AI 出错时提示检查网络或账户余额。

固定 NPC 为父亲、母亲、先生、同窗、考官和书商。对话按当前场景和本场历史进行，可以完成交易；玩家或 AI 结束整场对话时，才统一结算属性变化。NPC 使用与玩家相同的数据和行动入口，但不会在后台自动生活。

## 四、读书与成长

七本学校教材需要向先生免费领取，另外三本付费书由集市书商提供。免费不等于开局赠送；拿到书后，还要满足年龄、属性、能力和前置阅读条件。

每本书保存独立阅读进度，读完可以继续温习。科举类书籍还支持“以身入局读书”：先生提出问题，玩家亲自写体会，按评分增加10～90点进度，实际不超过剩余进度；满分增加90点，适合先普通读书再提交体会。特殊书《GPT-1的权重》不提供此入口。学识汇总所有读过的书，同一本书多买几本不会重复增加学识；失去书籍也不会清空已学进度。书单、价格与计算方法见[规则与数值](./规则与数值.md#三教材与价格)。

《GPT-1的权重》保留为穿越题材彩蛋。政治类书籍和高层任职必读条件属于[后续设计](../后续设计/政治书籍与任职阅读门槛.md)。

## 五、考试与结束

玩家八岁、十二岁、十五岁分别进行蒙学阶段考、经义阶段考、县试预考；十六岁参加县试。四场节点考试始终由玩家参加，不由最后行动的 NPC 替代。前三场无论通过与否都继续求学，玩家县试结算后结束本局。

考试目标有两种方式：系统代行按角色能力作答；“以身入局”由玩家亲自输入答案，内容评价影响分数，但不替代角色能力。题目前展示角色水平对应的思路，不直接给完整答案。成绩由程序确定，AI 只能据此生成答卷、评价和总结。

后端已接入两种作答方式、思维提示、AI 答卷和考试总结。思维提示按考试缓存，不消耗回合；系统代行先由程序计分再生成答卷，玩家作答先评价原文，再由程序应用最多 ±10 分的内容修正并生成总结。模型失败不交卷、不推进阶段，可重试；成功交卷后不能改换答案或作答方式。

## 六、页面与完成标准

| 页面 | 需要展示的内容 |
| --- | --- |
| 入口与存档 | 新开局、读档、姓名、年龄、日期、身份、创建时间；未知身份留空 |
| 出生 | 角色名、博罗县或海丰县 |
| 成长 | 人物状态、能力、学识、钱包、家庭背景、所在地、场景、背包、NPC 与行动 |
| 考试 | 题目、系统代行、玩家作答与角色思路 |
| 结果 | 县试成绩、关键经历与本局结束提示 |

完成标准：能从出生页走到县试结束；时间和考试节点正确；阅读进度与考试分数使用整数；两种考试方式可用；AI 结果经过程序处理后才写入存档。阶段考试复用考试页，完成后回到成长页。

## 七、本阶段不做

动态地图、移动耗时、后台 NPC 行动、完整行政区、官职权限、政策、战争、完整商业经营、府试、院试和县试后的生活均不在 MVP 范围内。商人售书只做基本交易。[随机种子](../后续设计/随机种子.md)和复杂的跨存档并发处理也延后。
