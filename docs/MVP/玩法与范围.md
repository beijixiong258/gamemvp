# MVP 玩法与范围

《豪杰成长计划plus》先实现单人网页游戏。启动见[启动与部署](../开发者手册/启动与部署.md)，公式与参数见[规则与数值](规则与数值.md)。

## 开局与流程

填写 2～8 字姓名、选择博罗或海丰 → 六岁入塾 → 领书、阅读、练习、休息与互动 → 八岁蒙学考、十二岁经义考、十五岁县试预考 → 十六岁县试后结束。前三场考试无论通过与否都继续求学。

开局为 1547 年（嘉靖二十六年），不模拟零至五岁的逐年回合。家庭有田产与积蓄，可供求学；钱包和家庭财富分开。新局建立独立存档，固定初值不依赖 AI；童年叙事可单独生成，成功后复用，失败不影响继续游戏。

1547 年为夏言最后一次执政的倒数第二年；他于嘉靖二十四年九月复入内阁，二十七年正月罢职。历史提供起点，之后以本局事实为准。[《明史·世宗二》](https://zh.wikisource.org/zh-hans/%E6%98%8E%E5%8F%B2/%E5%8D%B718)

地区采用广东—广州/惠州—五县的简化树，只开放惠州下的博罗、海丰出生。现代机构需求按游戏背景命名，地图、房间和固定 NPC 集中见[前端页面与交互](前端页面与交互.md)，官署见[官职与爵位](../后续设计/官职与爵位.md#27-官署名称与地图入口)。

## 交互原则

- 读书、练习、休息和自由行动消耗回合；浏览、同县地点切换、领书、购买和普通对话不消耗。重病按规则强制休养。
- 七本教材向窦苞免费领取，三本付费书向陆掌柜购买。持有后仍须满足阅读条件；多份副本不重复计学识，失去书籍不清空进度。进度达到100后标记“已完成”，不能再次阅读或写体会。
- 科举书可“以身入局”读书：塾师提出体会题，玩家写体会，AI 评阅后由程序增加阅读进度。《GPT-1的权重》支持普通阅读，暂不开放“以身入局”写体会。
- 自由行动和对话依据场景、实际在场 NPC、本场历史及人物自己的记忆；交易与属性只认程序结算。每场对话最多五轮，AI 可提前结束，第五轮必须返回终止标志。
- 考试可系统代行或亲自作答，角色能力决定基本水平，玩家内容影响有限修正。思路按角色能力生成；模型失败不交卷，成功后不能更换答案或方式。
- 玩家与 NPC 共用人物、领域档案和行动结构，共享时间线；固定 NPC 无后台作息。节点考试始终归玩家。
- 记忆只来自实际参与的已确认经历。压缩正文存 JSON，数据库存索引；后续携带的记忆整体不超过 5000 个 Unicode 字符。摘要失败不撤销已完成事件。
- 领域能力可并存，不设互斥主职业。MVP 只实现书生领域，其他领域与县试后人生见[后续规划](../后续设计/后续规划.md)。

## 当前状态

存档、开局、书籍与背包、固定及自由行动、五轮对话、压缩记忆、童年叙事、四场考试的两种作答方式，以及五类前端页面均已实现源码。卧室、书房、主卧、讲堂、藏书阁的行动和人物在场校验已接入，旧存档通过补内容接口接入窦苞与沈砚。

完整运行与数值节奏仍待手动试玩：从开局走到县试结束，确认旧存档补齐、房间交互、时间节点与两种作答方式。阅读进度和成绩使用整数，所有 AI 影响经程序处理后才入库。

## 已知限制

- 公共装备定义首次导入采用先查询后插入，多存档同时初始化仍可能发生唯一编码冲突，未增加全局锁。
- 记忆缺口在后续相关调用中少量补齐，不保证模型失败后立即具备完整历史。数据库和记忆文件须一起保留。
- 旧版本误把玩家节点考试记到 NPC 名下的存档，可能缺少玩家待考记录或阶段错误；不自动改写历史考试与请求结果，需先核对再修正。
- 当前没有账号及按用户的存档权限，换浏览器也不能查询全部未结束对话。公网多人使用前需补齐这些能力。
- 动态地图、移动耗时、后台 NPC、完整行政区、官职权限、政策、战争、完整商业经营、府试、院试、县试后生活、随机种子及复杂跨存档并发处理均属后续范围。
