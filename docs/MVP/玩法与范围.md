# MVP 玩法与范围

《豪杰成长计划plus》是明代背景的单人网页回合游戏，MVP 完整覆盖书生求学线。启动见[启动与部署](../开发者手册/启动与部署.md)，公式与参数见[规则与数值](规则与数值.md)，页面与地点见[前端页面与交互](前端页面与交互.md)。

## 开局与流程

填写 2～8 字姓名、选择博罗或海丰 → 六岁入塾 → 领书、阅读、练习、休息与互动 → 八岁蒙学考、十二岁经义考、十五岁县试预考 → 十六岁县试后结束。前三场考试无论通过与否都继续求学。

开局为 1547 年（嘉靖二十六年），不模拟零至五岁的逐年回合。每月 3 回合，一年 36 回合，正常时间线在累计 360 回合到达十六岁县试。家庭有田产与积蓄，可供求学；钱包和家庭财富分开。新局建立独立存档，固定初值不依赖 AI；童年叙事可单独生成，成功后复用，失败不影响继续游戏。

1547 年为夏言最后一次执政的倒数第二年；他于嘉靖二十四年九月复入内阁，二十七年正月罢职。历史提供起点，之后以本局事实为准。[《明史·世宗二》](https://zh.wikisource.org/zh-hans/%E6%98%8E%E5%8F%B2/%E5%8D%B718)

地区采用广东—广州/惠州—五县的简化树，只开放惠州下的博罗、海丰出生。同县房间和书铺供玩家选择，导航不消耗时间。

## 行动与资源

- 读书、练习、休息和自由行动消耗回合；浏览、同县地点切换、领书、购买、拾取、使用清茶和普通对话不消耗。重病按现行规则强制休养 4 回合。
- 七本教材向窦苞免费领取，每个人物每种教材限领一次，每次一份。三本付费书向陆掌柜购买；持有后仍须满足阅读条件，多份副本不重复计学识。进度达到 100 后完成，不再阅读或写体会。
- 初始钱包为 2000 文，三本付费书合计 2000 文。清茶每份 20 文，使用后疲劳最多减少 10，无疲劳时不消耗物品。固定目录不模拟供应者库存；书生线没有额外收入、出售或经营收益，买书与消耗品共同使用这笔预算。
- 科举书可“以身入局”读书：塾师提出体会题，玩家写体会，AI 评阅后由程序增加阅读进度。《GPT-1的权重》只支持普通阅读。
- 自由行动和对话依据场景、在场人物、本场历史及人物自己的记忆。每场对话最多五轮，AI 可以提前结束，第五轮必须结束；整场属性变化只结算一次，使用现有驱动量限幅。
- 考试可系统代行或亲自作答，角色能力决定基本水平，玩家内容提供有限修正。思路按角色能力生成；模型失败不交卷，完成后不能更换答案或方式。

阅读、考试、属性及健康沿用[规则与数值](规则与数值.md)的公式。能力收益分别取整，不累计余数；没有隐藏的成长补偿或额外对话收益表。

## 人物、物品与记忆

固定 NPC 长期保存，动态 NPC 可以在行动中随用随创。L0 保存稳定身份供当回合连续交互；L1 跨回合保留 3／9／18 回合；L2 长期保存。真实互动可以续期或升级，单纯查看不延长期限。到期人物退出日常人物列表，历史引用保留；活跃对话保护双方，不会在交谈途中因为到期失去对象。玩家与 NPC 共用人物、书生档案和时间线，节点考试始终归玩家，不模拟后台作息。

场景小物也分 L0／L1／L2，由已确认的行动创建或更新。小物在场景中出现不代表已进入背包；玩家拾取后沿用原 ID、进入行囊并成为 L2。已持有的书籍、清茶和动态小物不会因为记忆到期消失。动态物品承载叙事线索，不能由模型擅自附加数值效果或交易权限。

人物身份、物品实例和经历记忆分别保留。跨场记忆来自实际参与的已确认经历，分为 L0 当场、L1 近期、L2 长期；正文存 JSON，数据库保存索引和保留策略。关系经历及明确约定可影响后续回应，确有关系或约定的动态人物会长期保留。记忆上下文最多 8 条、整体不超过 5000 个 Unicode 字符。

同一回合内的经历按事件序号区分先后，回合只负责游戏时间和到期。个人记忆不向旁人扩散；新出现的人物不会自动获得此前整场私人对话。已执行交易、人物身份和场景物件以程序回执为准，模型叙述不替代所有权和数值结算。手动结束对话不会把未发送草稿当成真实发言。

## 保存与恢复

存档、人物、进度、交易、考试和事件保存在数据库，记忆正文位于对应的 `memory/<saveId>/` 目录，两者共同组成存档。模型摘要失败不撤销已完成事件；后续检索少量补齐活跃缺口，主动归档的记忆不重新生成。

写请求带稳定编号，结果不明时重试原请求；同编号不能改参数。浏览器保存当前地点、草稿、对话 ID 及待确认请求，服务端结果决定时间和阶段。换浏览器不会丢失数据库中的存档，但浏览器本地草稿不会同步；恢复方法见[前端说明](../../src/frontend/README.md#请求恢复)。

## 范围边界

MVP 是单人书生线，县试后结束。明确不包含数值好感、独立任务状态、自动履约、官职权限、政策、战争、完整商业经营、府试、院试及县试后职业人生。长期约定记录不自动发奖、扣款或完成任务。其他职业设计另见[后续规划](../后续设计/后续规划.md)，官制资料见[官职与爵位](../后续设计/官职与爵位.md)，不作为本线功能的替代方案。

单机使用不提供账号及按用户的存档权限，也不模拟动态地图、跨县旅行耗时、完整行政区、后台 NPC 或可复现的随机种子。公共服务开放方式和运行环境见[启动与部署](../开发者手册/启动与部署.md)。
